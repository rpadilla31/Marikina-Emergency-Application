# Emergency Response Tracking Application

## Overview
The **Emergency Response Tracking Application** is a vital mobile platform designed to connect individuals in crisis with immediate emergency dispatch services. This application bridges the gap between distressed users and emergency responders by providing location-based tracking and real-time status updates, ensuring that help is dispatched and monitored efficiently.

## 🌟 Key Features

### User Module
*   **Emergency Dispatch Request:** Users can quickly request specific emergency services (e.g., medical or fire) directly from their mobile devices.
*   **Responder Tracking (In Development):** Users will be able to monitor the real-time status and location of the dispatched emergency units to see if help is on the way (OTW).

### Admin / Dispatcher Module
*   **User Location Monitoring:** Admins can pinpoint the exact geolocation of the user requesting help.
*   **Resource Management:** Admins can manage and dispatch available emergency vehicles based on the proximity and nature of the emergency.

### Supported Emergency Units
*   🚑 **Ambulance:** For medical emergencies and health crises.
*   🚒 **Firetruck:** For fire-related incidents and rescue operations.
*   🚓 **Police / PNP:** *(Currently in processing - see Roadmap)*
